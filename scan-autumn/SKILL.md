# 秋天股票掃描器

根據權證小哥「股票四季理論」，掃描台股中處於秋天階段（漲多轉弱）的股票。僅掃描有股票期貨的標的，方便做空操作。

## 快速使用

掃描所有有股票期貨的標的：
```bash
/scan-autumn
```

掃描指定股票：
```bash
/scan-autumn 2330 2454 3443
```

只看高危險群（5 分以上）：
```bash
/scan-autumn --min-score 5
```

## 執行方式

收到此 skill 指令後，請執行以下步驟：

1. 解析使用者傳入的參數，判斷是否包含 `--min-score` 或 `-m` 以及股票代號
2. 執行掃描腳本：

```bash
python3 {SKILL_DIR}/scripts/autumn_scanner.py $ARGUMENTS
```

其中 `$ARGUMENTS` 是使用者傳入的完整參數。如果沒有傳入參數，則掃描所有有股票期貨的標的。

3. 將結果整理後回報給使用者

## 篩選條件（共 8 項）

| # | 條件 | 判斷邏輯 | 觀察面向 |
|---|------|---------|---------|
| 1 | 高檔區 | 收盤價 >= 近 120 日高點 × 90% | 價格位置 |
| 2 | 漲勢鈍化 | 近 10 日漲幅 < 前 10 日漲幅，且前 10 日 > 0 | 動能趨勢 |
| 3 | 量價背離 | 股價距高點 5% 內，但成交量 < 20 日均量 | 量能 |
| 4 | 黑 K 頻現 | 近 10 日黑 K >= 5 根 | K 線型態（散佈） |
| 5 | KD 滑落 | 近 10 日 K 曾 >= 80，目前已回落至 80 以下 | 技術指標（擺盪） |
| 6 | MACD 減弱 | 柱狀體（OSC）> 0 但開始縮小 | 技術指標（趨勢） |
| 7 | 均線鬆動 | 5MA < 10MA 或 10MA < 20MA | 均線結構 |
| 8 | 連續黑 K | 近 5 日出現連續 >= 3 根黑 K | K 線型態（連續性） |

分數 >= 3/8 才會列入結果。

## 回覆摘要固定格式（重要）

執行腳本後，回覆使用者時 **必須依序呈現以下三段 markdown 表格**：

### 第一段：高危險群（5 分以上，秋意濃厚）

完整欄位 markdown 表格：

```
| 代號 | 收盤價 | 漲跌% | 分數 | 距高點% | 量比 | K值 | D值 |
```

- 分數 >= 6 以粗體 + 警示標出（如 `**7/8**`）
- 代號以粗體標出

### 第二段：條件檢核矩陣

8 條件對應欄位的矩陣表，每檔以 ✅/❌ 標示：

```
| 代號 | 高檔區 | 漲勢鈍化 | 量價背離 | 黑K頻現 | KD滑落 | MACD減弱 | 均線鬆動 | 連續黑K | 分數 |
```

### 第三段：操作建議

依分數等級給出建議：
- **7-8/8 分**：極度危險！強烈建議獲利了結，可考慮股期做空
- **5-6/8 分**：秋意濃厚，應減碼或停止加碼
- **3-4/8 分**：初秋訊號，提高警覺、設好停損

### 三段後可附加
- 動能詳細資訊（漲幅比較、KD 歷史、OSC 數值）
- 個別股票的缺項說明
- 結合大盤走勢的整體判斷

**說明**：所有列出的標的均有股票期貨，可直接用股期做空來獲利。請勿省略任何一段。
