# 布林通道起漲點掃描器

掃描台股中符合布林通道起漲條件的股票，包含 5 大判斷指標：站上上軌、量能放大、中軌上彎、收窄開口、收紅K。

## 快速使用

掃描預設股票清單：
```bash
/scan-bollinger
```

掃描指定股票：
```bash
/scan-bollinger 2330 2454 3443
```

回測某一天的訊號：
```bash
/scan-bollinger --date 2026-03-15
/scan-bollinger --date 2026-03-15 2330 2454
```

## 執行方式

收到此 skill 指令後，請執行以下步驟：

1. 解析使用者傳入的參數，判斷是否包含 `--date` 或 `-d` 以及股票代號
2. 執行掃描腳本：

```bash
python3 /Users/beanlin/bollinger_scanner.py $ARGUMENTS
```

其中 `$ARGUMENTS` 是使用者傳入的完整參數（包含 --date 和股票代號）。如果沒有傳入參數，則掃描預設清單的最新資料。

2. 將結果整理後回報給使用者，重點說明：
   - 5/5 滿分的強烈起漲訊號標的
   - 4/5 高機率起漲標的
   - 特別值得關注的個股及原因（例如量比特別大、帶寬剛開口等）

3. 如果掃描結果為空，建議使用者：
   - 可能處於大盤整理期
   - 可嘗試放寬條件或擴大掃描範圍

## 判斷條件說明

| 條件 | 說明 |
|------|------|
| 站上上軌 | 收盤價 >= 布林上軌 * 0.98 |
| 量能放大 | 成交量 >= 20日均量 * 1.5 |
| 中軌上彎 | MA20 近 3 日斜率為正 |
| 收窄開口 | 帶寬曾收窄至歷史 25% 以下且正在擴張 |
| 收紅K | 收盤價 > 開盤價 |

分數 >= 3/5 才會列入結果。
